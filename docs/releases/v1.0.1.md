# Что нового в релизе v1.0.1

### Адаптивная верстка и геометрия экрана
- **Адаптивная высота рядов для 3 ИИ-агентов:** При одновременной активности всех трех агентов (Claude, GPT, Antigravity) и датчиков домашнего климата верхний ряд автоматически расширяется до 328 px. Это полностью предотвращает наложение блоков на разделитель.
- **Подняты плашки статуса климата:** Плашки «СВЕЖО» и «НОРМА» теперь строго выровнены по нижнему краю спарклайна графика тренда, оставляя аккуратный зазор в 12 px до разделительной линии рядов.
- **Динамический список почты:** Виджет входящей почты динамически подстраивает количество отображаемых писем (3–4 письма при расширенном верхнем ряде или до 5 писем в стандартном режиме) без обрезания текста.

### Сборка и стабильность
- **Кроссплатформенная сборка хостового рендерера:** Исправлена компиляция рендерера на macOS и окружениях без Linux Framebuffer.
- **OTA и синхронизация версий:** Внутренний номер версии демона обновлен до v1.0.1 для корректной работы проверки обновлений по воздуху.

### Загрузки
- `PocketBook-tablo-v1.0.1.zip` — архив для ручной установки через USB (распаковать в корень книги).
- `update.tar.gz` — пакет для беспроводного обновления через веб-интерфейс (`http://pb-tablo.local:8080`).
