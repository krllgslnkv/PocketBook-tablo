## What's Changed in v1.0.1

### Layout & UI
- **Adaptive layout for multiple AI agent quotas:** Automatically adjusts row heights when monitoring Claude, GPT, and Antigravity alongside climate widgets to eliminate overlaps and maintain clean typography.
- **UI alignment fixes:** Corrected status badge vertical alignment and margin spacing above row dividers.
- **Dynamic mail rows:** Email list automatically scales visible items based on available screen space.

### System & Build
- **Renderer portability:** Added native build support on macOS and hosts without Linux framebuffer.
- **Version bump:** Internal daemon version synced to v1.0.1 for OTA updates.
