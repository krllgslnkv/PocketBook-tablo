# Первый стабильный релиз Tablo для PocketBook (v1.0.0)

Полноценный автономный порт e-ink дашборда Tablo для электронных книг PocketBook (Basic, Touch Lux, Touch HD и совместимых моделей с архитектурой ARMv7).

### Основные возможности

- **Автономный фоновый демон:**
  - Написан на Go, запускается без модификации системного раздела книги.
  - Управляет опросом источников, отрисовкой кадров и энергосбережением.

- **Встроенный веб-портал настройки:**
  - Доступен по адресу `http://pb-tablo.local:8080` (через mDNS).
  - Позволяет настраивать Wi-Fi, токены API, виджеты, часовой пояс, интервалы опроса и модель экрана читалки.

- **Поддержка трех ИИ-агентов:**
  - Мониторинг лимитов и квот Claude (5-часовое и недельное окно).
  - Мониторинг квоты OpenAI / GPT.
  - Мониторинг квоты Antigravity с отображением остатка и времени сброса.

- **Информационные виджеты:**
  - Финансовые рынки: график курса BTC за 24 часа, курсы валют USD/RUB и EUR/RUB.
  - Домашний климат: температура, влажность, CO₂ и TVOC с графиками истории.
  - Электронная почта: счетчик непрочитанных и последние письма по IMAP.
  - Погода на день и события календаря.

- **Энергосбережение:**
  - Полный перевод модуля Wi-Fi в спящий режим между циклами обновления кадра.

### Загрузки
- `PocketBook-tablo-v1.0.0.zip` — архив для ручной установки через USB.
- `update.tar.gz` — пакет беспроводного обновления (OTA).
