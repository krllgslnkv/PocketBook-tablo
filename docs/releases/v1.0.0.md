## Release v1.0.0

Initial stable release of Tablo for PocketBook e-readers (ARMv7 architecture).

### Features
- **Standalone Go Daemon:** Runs in the background without modifying system partitions.
- **Web Setup Portal:** Built-in configuration portal at `http://pb-tablo.local:8080` for Wi-Fi, API tokens, display model, and widget setup.
- **AI Agent Monitoring:** Live quota and rate limit tracking for Claude, GPT, and Antigravity.
- **Dashboard Widgets:**
  - Market rates: 24h BTC price chart, USD/RUB and EUR/RUB tickers.
  - Climate & air quality: Temperature, humidity, CO₂, and TVOC tracking.
  - Mail & calendar: Unread count, recent IMAP emails, and daily schedule.
- **Battery Optimization:** Full Wi-Fi sleep mode between refresh cycles.

### Downloads
- `PocketBook-tablo-v1.0.0.zip` — USB installation archive.
- `update.tar.gz` — OTA wireless update archive.
